# Security

This repository is a synthetic portfolio/demo project, not production healthcare software. It does not provide a security or compliance certification.

- Do not submit real patient, member, or payer data in issues or pull requests.
- Do not commit API keys, credentials, `.env` files, or `.streamlit/secrets.toml`.
- Use synthetic data only when reproducing a problem.
- If repository hosting offers private vulnerability reporting, use that channel for security issues rather than publishing sensitive details. No dedicated security contact is configured in this repository.
- Do not treat the demo as suitable for production healthcare or financial workflows.
